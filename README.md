# defiguard-app.js-FIXED
APP.JS
💳 DeFiGuard – ETH Wallet UI (Web3.js)
📌 Overview
This project is a simple Ethereum wallet interface built with React and Web3.js.
It allows users to connect a MetaMask wallet, view ETH balance, and send ETH transactions directly from the browser.
The project was developed as a technical assessment to demonstrate frontend Web3 integration and blockchain interaction handling.
⚙️ Features
🔗 Connect MetaMask wallet
💰 Display ETH balance
📤 Send ETH transactions
⚡ Real-time wallet interaction using Web3.js
🧠 Simple and clean UI for usability
🛠️ Tech Stack
React (Create React App)
Web3.js
JavaScript (ES6+)
MetaMask (Ethereum wallet provider)
📂 Project Structure

src/
 ├── App.js          # Main wallet UI logic
 ├── index.js        # React entry point
public/
 ├── index.html      # App root container
🚀 Getting Started
1. Clone repository
Bash
git clone https://github.com/joycjoy50-spec/defiguard-app.js-FIXED.git
2. Install dependencies
Bash
npm install
3. Install Web3.js
Bash
npm install web3
4. Start development server
Bash
npm start
Then open:

http://localhost:3000
🔐 Requirements
MetaMask extension installed
Ethereum account connected
Testnet or mainnet ETH for transactions
🧪 How to Test
Click Connect Wallet
Approve MetaMask connection
Check ETH balance display
Enter recipient address and amount
Confirm transaction in MetaMask
📌 Notes
This project is intended for demonstration and testing purposes.
Transactions depend on MetaMask and Ethereum network availability.
Ensure wallet is connected before sending transactions.
